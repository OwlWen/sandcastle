# 用户已有 TypeScript / git worktree / Effect-TS 基础

用户声明对 TypeScript、git worktree 和 Effect-TS 三者都有一定了解，目标是深入精读 WorktreeManager.ts 源码。

## Implications
- 不需要从零解释 TypeScript 语法或 git worktree 基本概念
- 课程可以直接进入代码层面的分析，重点放在"为什么这样设计"而非"这是什么"
- Effect-TS 的讲解聚焦于本模块实际使用的模式（gen / async / catchAll / either），不需要覆盖框架全貌
